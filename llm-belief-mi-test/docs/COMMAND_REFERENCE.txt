KEY PARAMETERS (FROM PAPER)
────────────────────────────────────────────────────────────────────────
--k 10                # Number of chains (paper line 839)
--n 2                 # Chain length (paper line 839)
--temperature 0.9     # Sampling temperature (paper line 799)
--max-tokens 30       # Optimized for MCQ (covers 95%+ answers)
--load-in-4bit        # Saves VRAM (6GB vs 16GB)
